# 자동 업로드 설정 (처음 한 번, 약 30분)

설정이 끝나면 이렇게 돌아갑니다.

| 언제 | 무엇이 | 누가 |
|---|---|---|
| 매일 07:30 무렵 | 오늘의 카드뉴스 게시 | GitHub가 자동으로 |
| 매일 20:30 무렵 | 전날 주제의 릴스 게시 (음악 없음, 프로필 격자에는 안 보이고 릴스 탭·추천에만) | GitHub가 자동으로 |
| 매주 일요일 저녁 | 원고가 2주 치보다 적게 남으면 다음 주 7개를 새로 만들고 미리보기를 보냄 | Claude가 자동으로 |
| 미리보기를 받으면 | 훑어보고 **"OK"** 또는 고칠 점 답장 | **나** (주 10~15분) |

> 승인하지 않은 원고는 **절대 자동으로 올라가지 않습니다.** 원고가 없거나 승인 전이면 그날은 건너뛰고, GitHub에서 알림 메일이 옵니다.

---

## 1단계. Meta에서 '업로드 열쇠(토큰)' 받기

1. 컴퓨터로 **developers.facebook.com** 접속 → 페이스북 계정으로 로그인
   - 처음이면 개발자 등록(이메일·전화 인증)을 해요.
2. **내 앱** → **앱 만들기**
   - 앱 이름: `혈당노트 업로더` (아무거나 괜찮아요)
   - 사용 사례: **Instagram에서 메시지 및 콘텐츠 관리** 선택
   - 비즈니스 포트폴리오: **지금은 연결하지 않음**
   - **앱 만들기**
3. 왼쪽 **사용 사례** → Instagram API 옆 **맞춤 설정** → **Instagram 로그인을 통한 API 설정**
4. **액세스 토큰 생성** 항목에서 **계정 추가** → 혈당노트 인스타그램 계정으로 로그인 → 권한 **허용**
   - "테스터 초대"가 필요하다고 나오면: 앱의 **앱 역할 → 역할 → Instagram 테스터 추가** → 인스타그램 앱(또는 웹)의 **설정 → 웹사이트 권한 → 앱 및 웹사이트 → 테스터 초대**에서 수락
5. 계정 옆 **토큰 생성** → 나온 긴 글자를 **복사**

> ⚠️ 토큰은 **비밀번호와 같아요.** 채팅(Claude 포함)이나 카톡에 붙여 넣지 말고, 아래 2단계의 GitHub 비밀 칸에만 넣으세요.
> Meta 화면 문구는 자주 바뀌어요. 못 찾겠으면 **화면 캡처**를 Claude에게 보여 주세요(토큰이 보이는 부분은 가리고).

## 2단계. GitHub에 열쇠 넣기

1. **github.com/godjisu93-ui/Insta** → 위쪽 **Settings**(톱니바퀴)
2. 왼쪽 **Secrets and variables** → **Actions** → 초록 **New repository secret**
3. Name: `IG_ACCESS_TOKEN` (똑같이), Secret: 복사한 토큰 붙여넣기 → **Add secret**

## 3단계. 저장소를 공개로 바꾸기

인스타그램이 카드 이미지를 가져가려면 공개 주소가 필요해요.

1. **Settings** → **General** → 맨 아래 빨간 **Danger Zone**
2. **Change visibility** → **Change to public** → 확인 문구 입력

## 4단계. 연습으로 한 번 돌려 보기

1. 저장소 위쪽 **Actions** 탭 → (처음이면 초록 버튼 **I understand my workflows, go ahead and enable them**)
2. 왼쪽 **인스타그램 자동 업로드** → 오른쪽 **Run workflow ▾**
   - 무엇을 올릴까요: `carousel`
   - Day 번호: `2`
   - 연습 모드: **체크된 상태 그대로** (실제로 올라가지 않아요)
3. 초록 **Run workflow** → 3~5분 뒤 **초록 체크 ✅**가 뜨면 준비 완료
   - 빨간 ❌면 클릭해서 빨간 줄의 글자를 Claude에게 보여 주세요.

이제 다음 날 아침부터 자동으로 올라갑니다. 🎉

## 자주 하는 조작

| 하고 싶은 것 | 방법 |
|---|---|
| **잠시 멈추기** (여행, 점검) | Claude에게 "자동 업로드 멈춰 줘" 또는 `schedule.json`의 `"paused": true` |
| **올라간 기록 보기** | 저장소의 `published.json` (게시 링크 포함) |
| **지금 바로 하나 올리기** | 4단계처럼 Run workflow, 연습 모드 **체크 해제** |
| **릴스에 음악 넣기** | 자동 업로드로는 인스타그램 음악을 넣을 수 없어요. 음악이 꼭 필요한 날은 그 릴스만 손으로 올리고 Claude에게 "day05 릴스는 내가 올렸어"라고 알려 주세요 |
| **토큰 만료** | 토큰은 60일짜리지만 매번 자동으로 연장돼요. 그래도 실패 메일이 오면 1단계 5번만 다시 하고 2단계에서 값을 바꿔 넣으세요 |

## 피드 체크무늬

카드뉴스 표지는 **홀수 Day = 진한 초록, 짝수 Day = 크림색**으로 번갈아 만들어져 프로필이 바둑판 무늬가 됩니다 (`brand.json`의 `coverPattern`). 고정 게시물은 **0개 또는 3개**일 때 무늬가 항상 맞아요.
