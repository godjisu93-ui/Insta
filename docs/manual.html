압축 푸는 법

1

Windows: zip 파일 마우스 오른쪽 클릭 → 압축 풀기 또는 모두 압축 풀기

2

Mac: zip 파일을 더블클릭하면 같은 자리에 폴더가 생겨요.

3

index.html을 더블클릭하면 브라우저에 모든 카드와 캡션, 업로드 전 확인할 점이 한 화면에 나와요.

폰으로 옮기는 법 (편한 것 하나만)

방법하는 법

구글 드라이브 / 네이버 MYBOX폴더째 올려 두고 폰 앱에서 하나씩 저장. 한 달 치를 한 번에 옮길 때 편해요.
에어드롭 (Mac → iPhone)파일 선택 → 공유 → AirDrop → 내 아이폰
💡 caption.txt는 폰으로 옮기지 않아도 돼요. 카톡 나와의 채팅에 내용을 복사해서 보내 두면 폰에서 길게 눌러 복사하기 편해요.

방법 1인스타그램에 올리기

📸 카드뉴스 (여러 장 게시물)

＋ 버튼→게시물→⧉ 여러 장 선택→01 → 02 → 03… 순서대로 탭→다음
1

사진을 고를 때 번호 순서대로 눌러야 카드 순서가 맞아요. 사진 위에 1, 2, 3 숫자가 떠요.

2

필터는 쓰지 마세요. 그대로 다음.

3

문구 쓰는 칸에 caption.txt 내용을 통째로 붙여넣기. (해시태그까지 들어 있어요)

4

(선택) 음악 추가: 카드뉴스에도 음악을 넣을 수 있어요. 잔잔한 곡 추천.

5

공유. 미리 예약하고 싶으면 공유 전에 고급 설정 → 예약(프로페셔널 계정) 또는 Meta Business Suite를 쓰세요.

🎬 릴스 (영상)

＋ 버튼→릴스→reel.mp4 선택→♫ 음악 추가→다음→커버 수정→공유
1

영상에는 소리가 없어요(정상). 인스타그램 안에서 ♫ 음악을 고르면 저작권 걱정 없이 쓸 수 있어요. 요즘 유행하는 곡을 고르면 더 많이 노출돼요.

2

커버 수정 → 카메라 롤에서 추가 → reel_cover.png를 고르면 프로필에서 깔끔하게 보여요.

3

문구는 같은 날 카드뉴스의 caption.txt를 그대로 써도 돼요.

4

'피드에도 공유'는 켜 두세요.

📅 추천 일정

· 매일 같은 시간에 카드뉴스 1개 (예: 아침 7~8시)
· 같은 주제의 릴스는 다음 날 저녁에 (예: 저녁 8~9시) → 하루 두 번 노출
· 올리고 1시간 안에 달린 댓글에 답하기 → 추천에 유리해요

⚠️ Day 0(계정 소개)은 올린 뒤 게시물 오른쪽 위 ⋯ → 프로필에 고정을 눌러 맨 위에 고정하세요.

방법 2Claude에게 말로 부탁하기

설치 없이, 지금 대화하는 것처럼 채팅으로 부탁하면 Claude가 원고를 쓰고 이미지·릴스까지 만들어 zip으로 보내 줘요.

시작하는 법

1

지금 쓰는 Claude Code(claude.ai/code 또는 Claude 앱)에서 새 대화를 열어요.

2

저장소(작업 폴더)를 godjisu93-ui/Insta로 골라요.

3

아래처럼 말하면 돼요. 복사해서 써도 좋아요.

이렇게 말해 보세요

day31부터 일주일치 원고 새로 만들어서 카드 이미지랑 릴스까지 zip으로 줘. 이미 다룬 주제는 빼고.
day05 두 번째 장 문구를 "힘이 되는 말 한마디"로 바꾸고 이미지 다시 만들어 줘.
댓글에 "귤은 하루 몇 개?"라는 질문이 왔어. 이걸로 카드뉴스 하나 만들어 줘.
브랜드 색을 따뜻한 주황 계열로 바꿔서 샘플 3개만 보여 줘.
다 끝나면 저장소에 저장(커밋, 푸시)까지 해 줘.
💡 "저장소에 저장해 줘"라고 꼭 말하세요. 대화가 끝나면 작업 공간이 사라지기 때문에, 저장하지 않은 원고는 다음 대화에서 볼 수 없어요.
⚠️ AI가 쓴 원고도 올리기 전에 꼭 한 번 읽어 보세요. 특히 숫자(혈당 수치, 분량)와 약 이야기는 대한당뇨병학회 진료지침과 맞는지 확인해야 해요. 각 원고의 '업로드 전 확인' 메모를 참고하세요.

방법 3내 컴퓨터에 설치하기 (한 번만)

직접 문구를 고치고 바로 이미지를 뽑고 싶을 때만 하세요. 처음 한 번 10분 정도 걸려요.

① 파일 내려받기 (GitHub)

1

인터넷 주소창에 github.com/godjisu93-ui/Insta 입력

2

왼쪽 위 ⑂ main ▾ 버튼 → claude/diabetes-instagram-… 선택
(main에 합쳐 두면 이 단계는 생략돼요. Claude에게 "main에 합쳐 줘"라고 부탁하세요)

3

초록색 <> Code ▾ → Download ZIP → 압축 풀기
추천 위치: 바탕화면 또는 문서 폴더. 폴더 이름은 Insta로 바꿔 두면 편해요.

② Node.js 설치

1

nodejs.org 접속 → LTS라고 적힌 버튼으로 내려받기

2

설치 파일 실행 → 계속 다음 / 계속만 누르면 끝

③ 터미널(명령어 창) 열기

Windows압축 푼 Insta 폴더를 열고 → 위쪽 주소창을 클릭 → cmd 입력 → Enter
검은 창이 뜨면 성공이에요.
MacInsta 폴더에서 마우스 오른쪽 클릭 → 서비스 → 폴더에서 새로운 터미널 열기
(메뉴가 없으면: 터미널 앱 실행 → cd 입력 후 한 칸 띄우고 폴더를 창에 끌어다 놓기 → Enter)

④ 처음 한 번만 입력 (한 줄씩, 입력 후 Enter)

npm install       # 필요한 프로그램 받기 (1~3분)
npm run setup    # 이미지 만드는 브라우저 받기 (1~3분)
💡 글자가 잔뜩 지나가도 괜찮아요. 맨 끝에 ERR(빨간 글씨)만 없으면 성공이에요. 다음부터는 ④는 건너뛰어요.

방법 3만들기 · 고치기

매번 쓰는 명령어 (터미널 열고 입력)

npm run build                # 전체 카드 이미지 만들기
npm run build -- day05       # day05만 만들기 (빠름)
npm run reels -- day05       # day05 릴스 영상 만들기
npm run check                # 원고에 실수가 없는지 검사만

결과는 Insta 폴더 → output 폴더에 생겨요. 구조는 2쪽과 똑같아요. (-- 앞뒤 띄어쓰기 주의)

무엇을 고치면 무엇이 바뀌나요?

파일바뀌는 것
brand.json계정 이름, @아이디, 색상, 면책 문구 → 모든 카드에 적용
content 폴더 → week1~4.json카드에 들어가는 문구, 캡션, 해시태그 (week1 = day00~07)
prompts 폴더 → AI프롬프트.md새 원고를 AI에게 부탁할 때 복사해 쓰는 문장

파일 여는 법: 마우스 오른쪽 클릭 → 연결 프로그램 → 메모장(Windows) / 텍스트 편집기(Mac). 더 편하게 쓰려면 무료 프로그램 VS Code를 추천해요.

문구 고치는 규칙 (예: week1.json)

{ "type": "cover", "title": "당뇨면 **과일**은\n무조건 끊어야 할까?", ... }
1

노란 부분, 즉 " " 따옴표 안의 글자만 고치세요. 따옴표, 쉼표, 괄호는 건드리지 않아요.

2

**과일**처럼 별 두 개로 감싸면 강조색이 돼요. \n은 줄바꿈이에요.

3

저장(Ctrl+S / ⌘+S) → 터미널에서 npm run build -- day01 → output에서 확인

💡 "글자가 70%로 작아졌습니다" 같은 안내가 나오면 그 장의 문장을 조금 줄이세요. 폰에서 더 잘 읽혀요.

막혔을 때

'npm'은(는) 내부 또는 외부 명령이 아닙니다 / command not found: npm
Node.js가 설치되지 않았거나, 설치 전에 열어 둔 터미널이에요. Node.js 설치 → 터미널을 닫고 다시 열기.
원고 오류: JSON 문법 오류 … week1.json
고치다가 따옴표(")나 쉼표(,)가 지워진 것이에요. 오류 메시지의 줄 번호 근처를 확인하세요. 모르겠으면 그 부분을 복사해서 Claude에게 "이거 고쳐 줘"라고 하면 돼요.
문구를 고쳤는데 이미지가 그대로예요
파일을 저장했는지 확인하고, npm run build -- dayNN을 다시 실행하세요. 릴스도 npm run reels -- dayNN을 다시 해야 바뀌어요.
릴스에 소리가 없어요
정상이에요. 인스타그램 앱에서 ♫ 음악을 넣어 주세요.
인스타에 올렸더니 카드 순서가 섞였어요
사진 고를 때 01 → 02 → 03 순서로 눌러야 해요. 올린 뒤에는 순서를 못 바꾸니 삭제 후 다시 올리세요.
그 밖의 모든 문제
화면을 캡처하거나 오류 글자를 복사해서 Claude에게 그대로 보여 주세요. 가장 빠른 방법이에요.

올리기 전 30초 체크리스트

  • 숫자(혈당 기준, 분량)가 진료지침과 맞는지 확인했다
  • 마지막 장에 출처가 있다
  • 약 이름·용량, "약 끊어도 된다" 같은 말이 없다
  • "낫는다 / 치료된다 / 혈당을 낮춘다" 같은 단정하는 말이 없다
  • 협찬이면 맨 앞에 "유료광고 포함"을 쓰고 유료 파트너십 라벨을 켰다
