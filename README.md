# 혈당노트 · 당뇨 카드뉴스 자동 생성기

당뇨병 환자·가족을 위한 인스타그램 카드뉴스를 **원고(JSON)만 쓰면 이미지로 자동 생성**하는 도구입니다.
30일 치 원고(Day 0~30)가 이미 들어 있습니다.

```
원고 작성(AI 초안 + 사실 확인)  →  npm run build  →  output/dayNN/01.png ~ + caption.txt  →  예약 업로드
```

> 📘 **처음이라면 `docs/혈당노트_사용설명서.pdf`부터 보세요.** (설치 없이 쓰는 법 포함, 7쪽)

## 1. 처음 한 번만: 설치

1. [Node.js](https://nodejs.org) LTS 버전 설치
2. 이 폴더에서 터미널을 열고:
   ```bash
   npm install
   npm run setup     # 이미지 생성용 브라우저(Chromium) 설치
   ```

## 2. 이미지 만들기

```bash
npm run build                 # 전체 원고 → 이미지
npm run build -- day05        # 특정 원고만
npm run build -- day05 day06  # 여러 개
npm run check                 # 이미지 없이 원고 형식만 검사
npm run reels -- day05        # 릴스 영상(1080×1920, 9:16) 만들기
```

- 릴스: `output/day05/reel.mp4` + `reel_cover.png`. 카드가 옆으로 넘어가는 15~20초 영상이며, **소리는 없습니다**(인스타그램 앱에서 음악 추가). 장당 시간은 `scripts/render-reels.mjs`의 `SEC`에서 바꿉니다.

- 결과: `output/day05/01.png, 02.png …` (1080×1350, 인스타그램 세로형 4:5)
- 같은 폴더의 `caption.txt` = 본문 + 면책 문구 + 해시태그 (복사해서 붙여 넣기)
- `output/index.html`을 브라우저로 열면 전체 미리보기와 **업로드 전 확인 사항**을 한눈에 볼 수 있습니다.
- 글이 너무 길면 자동으로 글자를 줄이고, 그래도 넘치면 터미널에 경고가 나옵니다.

## 3. 브랜드 바꾸기 → `brand.json`

| 항목 | 설명 |
|---|---|
| `accountName` | 표지 왼쪽 위에 표시되는 계정 이름 |
| `handle` | 모든 장 아래에 표시되는 @아이디 |
| `disclaimer` | 마지막 장과 캡션에 들어가는 면책 문구 (지우지 마세요) |
| `colors` | 메인색(`primary`), 강조색(`accent`), 표지 강조색(`highlightOnDark`) 등 |

디자인 세부(글자 크기, 여백)는 `templates/card.css`에서 바꿉니다.

### 계정 이름 후보

| 이름 | 아이디 예시 | 느낌 |
|---|---|---|
| 혈당노트 (현재 적용) | @bloodsugar.note | 차분한 정보형, 저장하고 싶은 노트 |
| 당당한 식탁 | @dangdang.table | 식단 중심, 당뇨식 협찬과 잘 맞음 |
| 우리집 혈당코치 | @home.glucose.coach | 가족 대상, 따뜻함 |
| 오늘의 혈당 | @today.glucose | 매일 업로드 콘셉트와 잘 맞음 |

아이디는 인스타그램에서 사용 가능한지 먼저 확인하세요.

## 4. 새 원고 쓰기

1. `prompts/새원고_AI프롬프트.md`의 프롬프트로 AI에게 JSON 초안 요청 (일주일치 한 번에도 가능)
2. **사실 확인** (아래 체크리스트)
3. `content/posts/day31.json`으로 저장 (`content/` 아래 어디든, 한 파일에 한 개 또는 여러 개 배열)
4. `npm run build -- day31`

형식 예시는 `content/_template.json`을 보세요. 슬라이드 종류:

| type | 용도 | 예시 원고 |
|---|---|---|
| `cover` | 표지 | 모든 원고 1장 |
| `myth` | 오해 X / 사실 O | day01 |
| `text` | 소제목 + 문단 | day03 |
| `list` | 번호 목록 / `"style": "check"` 체크 목록 | day02 |
| `table` | 수치 기준표 (정상·주의·위험 색 구분) | day10 |
| `compare` | 이것 대신 → 이렇게 | day04 |
| `recipe` | 재료 + 만드는 법 | day06 |
| `end` | 핵심 요약 + 출처 + 면책 | 모든 원고 마지막 장 |

`**단어**`는 강조색, `\n`은 줄바꿈입니다.

## 5. 매일 빨리 올리는 루틴 (주 1회 2시간)

| 언제 | 할 일 | 시간 |
|---|---|---|
| 일요일 | 다음 주 7개 주제 정하기 (댓글·DM 질문 참고) | 15분 |
| 일요일 | AI로 일주일치 원고 → 사실 확인 → `npm run build` | 1시간 |
| 일요일 | 레시피는 완성 사진 촬영, 2번째 장으로 추가 | 30분 |
| 일요일 | Meta Business Suite에서 7개 예약 업로드 | 15분 |
| 매일 5분 | 댓글 답글, 스토리에 카드 1장 공유 | 5분 |

- 업로드 시간: 처음엔 오전 7~8시 / 저녁 8~9시 중 하나로 고정하고, 인사이트를 보며 조정하세요.
- 해시태그: 최근 인스타그램은 게시물당 해시태그 수를 적게 쓰는 방향이라 원고마다 **5개**만 넣었습니다.
- 반응 지표는 좋아요보다 **저장·공유 수**를 보세요. 협찬 단가에 가장 크게 영향을 줍니다.

## 6. ⚠️ 업로드 전 체크리스트 (의료 정보 계정 필수)

- [ ] 수치·기준을 **대한당뇨병학회 진료지침 최신판**과 대조했다 (원고마다 `check` 항목 참고)
- [ ] 마지막 장에 **출처**가 있다
- [ ] 약 이름·용량, 약 중단/조절 권유가 **없다**
- [ ] "치료된다 / 낫는다 / 혈당을 낮춘다" 같은 **단정 표현이 없다**
- [ ] 특정 병원·제품 이름이 없다 (협찬이 아닌 경우)

### 협찬을 받을 때

- 게시물 첫머리와 이미지에 **"유료광고 포함"** 명확히 표시 (공정위 추천·보증 심사지침), 인스타그램 '유료 파트너십' 라벨 사용
- **식품·당뇨식**: 일반식품에 질병 예방·치료 효능 표현 금지 (식품표시광고법). "혈당 관리에 좋은" 같은 표현도 주의
- **건강기능식품**: 식약처가 인정한 기능성 문구만, 자율심의를 거친 광고 문구 사용
- **병의원**: 의료광고는 의료법상 제한과 사전심의 대상이 될 수 있음. 치료 후기, 환자 유인형 콘텐츠는 피하고 **'전문의 감수·칼럼 협업'** 형태로 시작
- 규정은 자주 바뀌므로 계약 전 최신 기준을 확인하세요.

brand.json                 계정 이름·색상·면책 문구

content/_template.json     새 원고 형식 예시
CALENDAR.md                30일 캘린더 한눈에 보기
prompts/                   AI 원고 작성 프롬프트
templates/card.css         카드 디자인
scripts/render.mjs         카드 이미지 생성
scripts/render-reels.mjs   릴스 영상 생성
scripts/render-profile.mjs 프로필 사진 생성
scripts/make-manual.mjs    사용설명서 PDF 생성
docs/                      사용설명서 (PDF + 원본 HTML)
profile/                   프로필 사진·소개글
samples/                   결과 이미지 샘플
output/                    생성된 이미지 (git에는 올리지 않음)
