# 새 원고를 AI로 빠르게 만드는 프롬프트

아래 내용을 Claude 등 AI에 그대로 붙여 넣고 `[주제]`만 바꾸세요.
나온 JSON을 `content/posts/dayNN.json`으로 저장한 뒤 `npm run build -- dayNN` 하면 이미지가 나옵니다.

> ⚠️ AI 초안은 **반드시 사람이 사실 확인**하세요. 수치·기준은 대한당뇨병학회 진료지침 최신판과 대조합니다.

---

```
너는 당뇨병 환자와 가족을 위한 인스타그램 카드뉴스 작가야.
주제: [주제 예: 귤은 하루에 몇 개까지 괜찮을까?]
시리즈: [오해 vs 사실 / 이 음식 괜찮을까? / 숫자로 보는 당뇨 / 외식·편의점 가이드 / 가족 편 / 당뇨 레시피 / 한 주 정리]
id: [dayNN]

규칙
1. 근거: 대한당뇨병학회 진료지침, 식품교환표, 동료심사 논문만 사용. 마지막 장 source에 출처를 적고,
   확실하지 않은 수치는 쓰지 말고 check 항목에 "확인 필요"로 남겨.
2. 금지: 특정 약 이름·용량, 약 중단/조절 권유, "치료된다·낫는다·혈당을 낮춘다" 같은 단정,
   특정 브랜드·병원 이름.
3. 말투: 존댓말, 짧은 문장, 50~70대 부모님도 이해할 수 있게. 한 장에 핵심 하나.
4. 구성: cover 1장 → 본문 2~4장 → end 1장 (총 4~6장).
   본문 장에는 글을 많이 넣지 말 것 (heading 2줄 이내, 항목 3~5개, 항목 설명 1줄).
5. 강조는 **단어**, 줄바꿈은 \n.
6. caption은 5~8줄, 핵심을 ✔️ 목록으로, 마지막 줄은 댓글·저장·공유 유도. hashtags는 5개.

사용 가능한 slide type과 형식 (이 JSON 형식 그대로 출력, 설명 없이 JSON만):
{
  "id": "dayNN", "day": NN, "series": "...", "title": "...",
  "slides": [
    { "type": "cover", "tag": "시리즈명", "title": "...", "sub": "..." },
    { "type": "myth", "myth": "...", "fact": "...", "note": "..." },
    { "type": "text", "heading": "...", "body": ["...", "..."], "note": "..." },
    { "type": "list", "heading": "...", "items": [{ "title": "...", "desc": "..." }], "style": "check(선택)" },
    { "type": "table", "heading": "...", "rows": [{ "label": "...", "value": "...", "tone": "ok|warn|bad|info" }], "note": "..." },
    { "type": "compare", "heading": "...", "left": { "title": "...", "items": [] }, "right": { "title": "...", "items": [] } },
    { "type": "recipe", "heading": "...", "meta": "1인분 · 15분", "ingredients": [], "steps": [] },
    { "type": "end", "summary": ["...", "...", "..."], "question": "(선택)", "source": "..." },
    { "type": "quiz", "question": "...?", "hint": "(선택) 정답은 다음 장에 있어요 →" },
    { "type": "answer", "answer": "O 또는 X", "heading": "...", "body": ["..."], "note": "(선택)" },
    { "type": "poster", "tag": "(선택) 냉장고에 붙여 두세요", "heading": "...", "chips": ["(선택) 짧은 키워드"], "steps": [{ "title": "...", "desc": "..." }], "warn": "(선택) 빨간 경고 한 줄", "source": "..." }
  ],
  "caption": "...", "hashtags": ["..."], "check": "사람이 확인할 점"
}
```

## 형식 섞기 규칙 (2026-11 적용)

| 요일 슬롯 | 형식 |
|---|---|
| 월 · 오해 vs 사실 | **격주로 O/X 퀴즈**: 직전 월요일 슬롯이 '오해 vs 사실'이었으면 이번엔 퀴즈 (series: "O/X 퀴즈") |
| 일 · 한 주 정리 | **한 장 포스터** (series: "한 장 포스터", slides 1장, type "poster") |
| 나머지 | 기존과 동일 |

- **O/X 퀴즈** 구성: cover → quiz(문제) → answer(정답+설명) → (선택) table/list → end. 캡션 첫 줄은 질문, "정답 보기 전에 댓글로 O/X!"로 댓글 유도. 정답을 캡션에 쓰지 말 것.
- **한 장 포스터**: 그 주에 다룬 주제 중 **저장·인쇄할 가치가 큰 것**(대처법, 기준표, 고르는 법)을 한 장에. steps 3~4개, 각 desc 한 줄. 출처는 poster의 source에.
